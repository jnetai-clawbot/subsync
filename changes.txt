Features Implemented:
- Video file detection (mp4, mkv, avi, mov, flv, wmv, webm, m4v, mpg, mpeg, 3gp, ogv, ts)
- Simulated subtitle search and download with 10 language options
- SRT parsing and writing
- Sync correction (offset +/- ms, custom offset input)
- Timing scaling (speed factor)
- Subtitle translation (EN→ES, EN→FR, EN→DE)
- Translation toggle display
- Language selection picker
- Offline subtitle editing framework
- SRT export to app external files directory
- Full text search across all subtitle entries
- Dark Material Design 3 UI with green/teal neon accent colors
- Room database with 3 entities (VideoFile, SubtitleTrack, SubtitleEntry)
- Persistent debug logging with SS-xxx error codes
- Bottom navigation (Videos, Search, Settings)
- About section with jnetaol.com link
- Clear All Data functionality

Technical Specs:
- MinSdk 29, TargetSdk 34, compileSdk 34
- ARM64 only (arm64-v8a abi filter)
- Kotlin 1.9.22, Compose compiler 1.5.8
- Room 2.6.1 with KSP annotation processing
- Navigation Compose 2.7.6
- ProGuard rules for Room and models
